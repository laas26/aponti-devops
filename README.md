# 🚀 Aponti DevOps - Formação e Práticas

Repositório dedicado ao armazenamento de projetos, automações e práticas desenvolvidas ao longo da formação em DevOps pela Aponti.

---

## 🏗️ Arquitetura do Repositório

O repositório é organizado de forma modular, garantindo a separação entre a fundamentação teórica e as implementações práticas em código:

```text

├── .github/workflows/          # Esteiras automatizadas de CI/CD (SAST, SCA, DAST, GitGuardian)
├── modulo-devsecops/         # Resoluções práticas, scripts e documentação técnica
└── material-de-estudo/        # Slides, apostilas e enunciados divididos por módulos e unidades
                        
```
