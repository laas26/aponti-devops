# 🚀 Aponti DevOps - Formação e Práticas

Repositório dedicado ao armazenamento de laboratórios, automações e práticas desenvolvidas ao longo da formação em DevOps pela Aponti.

---

## 🏗️ Arquitetura do Repositório

O repositório é organizado de forma modular, garantindo a separação entre a fundamentação teórica e as implementações práticas em código:

```text
aponti-devops
├── .github/workflows/         # Esteiras automatizadas de CI/CD (GitHub Actions)
├── modulo-docker/             # Práticas de conteinerização e orquestração Docker
├── modulo-kubernetes/         # Práticas de orquestração com Kubernetes e Minikube
├── modulo-devsecops/          # Resoluções práticas, scripts de segurança e documentação
├── modulo-terraform/          # Infraestrutura como código (Terraform) e VMs (AWS)
├── labs/                      # Laboratórios práticos e exercícios de fixação
└── material-de-estudo/        # Slides, apostilas e enunciados divididos por módulos
                        
```
>📌 Este repositório é atualizado continuamente. As atividades, projetos e documentações são adicionados gradualmente de acordo com o progresso das aulas e módulos da formação.
