# Módulo Kubernetes

Este módulo contém as práticas, automações e documentações referentes ao aprendizado de **Kubernetes, orquestração de containers e gerenciamento de clusters locais com Minikube**.

---

## 🎯 Objetivos Gerais do Módulo

- Compreender a arquitetura do Kubernetes: control plane, nodes, pods e containers.
- Criar um cluster local com **Minikube** usando o **Docker** como driver.
- Gerenciar recursos com **kubectl**.
- Declarar aplicações por meio de **Deployments** e **Services**.
- Trabalhar com escalabilidade e **autocura** baseada no estado desejado.
- Desenvolver práticas reproduzíveis para portfólio e laboratório.

---

## 🛠️ Tecnologias e Ferramentas

- **Kubernetes**
- **Minikube**
- **kubectl**
- **Docker Desktop / WSL2**
